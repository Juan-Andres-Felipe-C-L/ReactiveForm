# ReactiveForm

Buena noche instructor Alejandro, soy el aprendiz Juan Andrés Felipe.

Aquí le entrego el código de un formulario hecho con la librería de Angular y con la ayuda de la IA Chat GPT. Éste consta de varios campos, entre lo cuales, se debe de ingresar información como: Nombre del usuario, edad, e-mail, un nombre de usuario y la creación de una contraseña. Cada campo es obligatorio y también tienen sus propias restricciones. Al final, el usuario debe de aceptar los "Terminos y condicones" y podrá hacer uso del botón de registro. Cabe acalarar que si todos los campos no son correctamente diligenciados, el botón "Registrarse" no se habilitará.

Por último, la información ingresada se mostrará en una tarjeta al lado izquierdo del formulario.

Gracias, instructor, por enseñarnos acerca de los "Reactive Forms"; sin sus ennseñanza no habría podido haber realizado esto.
